# BLDR

Mobile app built for climbers to connect, improve their skills, share new climbing spots & log climbs.

Extended from my group's project for: CS317, Mobile App Development.

## Features

- Create account
- Discover new boulders around you
- Logging of climbs, using phone sensors
- Share your climbs with others
- Profile page with username and profile picture changing
- Database of skills & resources to help you improve
- Android APK with download page
